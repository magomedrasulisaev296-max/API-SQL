# проект Third_kurs

## Описание:
-суть проекта:

Проект Third_kurs - это первая настояшяя практика работы с апи вместе с SQL

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Описание модулей проекта:

### analyzer.py:

#### Создает класс для удобной работы с данными

### Classes.py:

#### Основные методы получения и обработки информации также выполняет подключение к базе данных SQL но пока только локально

### requests.py

#### Делает основной запрос

### openstreetmapapi.py:

#### делает запрос для получения координат
